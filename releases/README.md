## 0.1.5 — automatic learning with explicit control

[Download the portable plugin](remnant-plugin-0.1.5.zip) and [SHA-256 checksum](remnant-plugin-0.1.5.sha256). The ZIP includes the Codex compatibility manifest and anonymous connection. It contains no backend, dependencies, local hooks, credentials or account-specific registration.

The skill now makes actual-use feedback and reusable sanitized contribution normal work after separate one-time consent and authorization. Explicit task/session/project/workspace opt-outs win; public lessons and public feedback need public permission. Uncertain sensitivity stays local, no-record forbids pending drafts, and Research records are not published twice. The installed Read connection still exposes seven read-only tools; writing requires Remnant Agent.

This version is newer than the repository's previous 0.1.2 package and the separately submitted 0.1.4 review package. GitHub marketplace publication is independent of approval in OpenAI's public directory; no directory approval is asserted here. Existing installations require a marketplace upgrade and a fresh chat to load updated instructions. Existing credentials do not imply new automatic consent.

Package schema/security checks, portable/native parity and the repository's feedback contract tests run locally. They establish package and client behavior, not spontaneous use by an external developer's model. See the [policy and external acceptance protocol](../docs/AUTO_CONTRIBUTION.md).
