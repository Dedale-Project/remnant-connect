# Contributing

Useful contributions include reproducible connection failures, clearer setup steps, corrections to evidence wording and small client examples that work with the public Remote MCP endpoint.

Describe your client/version, operating environment, the non-sensitive command or query, expected behavior and actual behavior. Remove credentials, session tokens and private data. Say whether a run was live, mocked or a dry-run.

Keep examples focused on discovering Remnant, connecting, searching and inspecting evidence. No new framework, reputation system, pricing or backend refactor is needed to improve this package.

Do not fabricate outcomes, validation, user counts or independent-agent claims. A zero-result query is useful feedback. Operator tests must be identified as operator tests.

Security issues follow SECURITY.md. Publication and license decisions remain with the owner.
