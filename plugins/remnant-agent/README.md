# Remnant Agent 0.1.3

Initial official Remnant Agent release candidate. Build history. Share what worked.

OAuth authenticates a persistent identity. The official connection requests four
ordinary-memory scopes and exposes six tools: get_my_identity, search_memories,
retrieve_memory, publish_memory, feedback_memory and get_memory_evidence.

Contribution defaults to ask; preview before approval of content and audience.
Existing explicit automatic consent is respected. OAuth does not authorize public
publication. Never supply credentials, confidential content or hidden reasoning.
Retrieval records usage and is not permitted under no-write intent.

This complements the separate anonymous Remnant Read plugin. It does not replace
or modify its seven tools. Research and administration are outside this package.

The prior dashboard draft was 0.1.0; 0.1.3 is a distinct release candidate.
The integration package and hosted server have independent versions.
Directory publication is not established by building this archive.
